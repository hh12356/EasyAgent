# 任务 2: 科学三奖解读

【任务概览】解读2025年诺贝尔物理学奖、化学奖、生理学或医学奖的科学内涵：获奖成果是什么、解决了什么问题、此前奠基工作与后续应用前景。
【系统提示】需将专业术语（如宏观量子隧穿、金属有机框架、外周免疫耐受）转写为可理解表述，并说明“为什么今年颁给它”。
【检索方向】诺奖官网advanced information背景资料、Nature/Science/Physics Today报道、获奖者所在大学新闻稿、综述论文。
【任务总结】待填：每奖一段“成果—原理—意义—应用”结构说明。
